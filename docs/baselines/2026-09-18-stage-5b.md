## Implemented boundary

1. Add validated IPC for provider/store/profile/page selection, paginated search,
   preparation cancellation, status and current iframe-Origin approval.
2. Persist exact local environment profiles and exclusive recording leases without
   exposing credentials, endpoints, raw target IDs, commands or arbitrary paths.
3. Convert the 5A prototype into a bundled production CDP sensor/adapter with exact
   process identity, single-channel coordination, trusted input, Locator/privacy
   reuse, frames/Popup/download mapping, sequence/dedup/buffering, reconnect and
   Stop/Flush/Gap handling.
4. Map fused evidence deterministically to sealed Blueprint v2 and export v2,
   timeline, Locators and explicit Gaps without model participation.
5. Keep the user store and original pages open. Do not add Analyzer, Evidence MCP,
   Builder, project execution, login recovery, business retries, or reports.

### Retained pre-fix Gap

The full real flow encountered one additional trusted click whose browser event
reported `button=-1`. The strict contract rejected it and persisted one Gap; every
required flow action was nevertheless present. The raw Gap remains immutable. The
sensor now normalizes trusted non-mouse click buttons to `0`, and a second real human
Shadow click using the built production sensor completed with zero Gap and successful
Flush. Unit tests also ensure validation errors no longer masquerade as connection
loss or expose raw Zod detail.
